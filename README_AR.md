# مخزني Pro — نسخة PWA

هذه النسخة مجهزة كتطبيق ويب تقدمي (PWA):
- Manifest للتثبيت كواجهة تطبيق.
- Service Worker للتشغيل مع التخزين المؤقت بعد أول زيارة.
- أيقونات 192 و512.
- اسم التطبيق: مخزني Pro.

## الخطوة التالية
يجب رفع ملفات هذا المجلد على استضافة HTTPS عامة، ثم استخدام رابط الموقع في أداة PWABuilder لتجهيز حزمة Android (AAB) للنشر على Google Play.

لا ترفع بيانات العملاء أو بيانات حقيقية أثناء الاختبار.
